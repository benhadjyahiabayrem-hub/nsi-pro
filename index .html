      Conseils pour le Bac NSI

      Structure du sujet

      3 exercices indépendants. Lisez-les tous avant de commencer et choisissez votre ordre.

      Algorithmes en Python

      Rédigez lisiblement, respectez l'indentation, commentez votre démarche.

      SQL

      Soignez la syntaxe. JOIN, GROUP BY et fonctions d'agrégation (COUNT, SUM) sont fréquents.

      POO & Récursivité

      Sachez définir une classe complète. Pour la récursivité, identifiez toujours le cas de base.

      Facile

      Traitement d'Image (PIL)

      Manipule les pixels d'une image : inversion des couleurs, passage en noir & blanc, filtre flou.

      300 XP
      Difficile

      Enquête SQL

      Une base de données contient des indices. Utilisez SQL pour retrouver le coupable.

      800 XP
      Moyen

      Labyrinthe Récursif

      Implémente un algorithme de backtracking pour explorer et sortir d'un labyrinthe généré.

      500 XP
      Moyen

      Chiffrement de César

      Implémente le chiffrement de César puis tente de déchiffrer un message codé par analyse de fréquences.

      400 XP
